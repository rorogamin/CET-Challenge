Catch-Em-Turing (CET)

Two agents, one shared tape, collision halts.

The model

  • A CET(n) machine has 2 agents, each with its own table of n states and the same k symbols.
  • Both agents start in state A. Agent 1 starts on cell 0, agent 2 on cell 2. The tape is blank.
  • Every step both agents read their cell, then write, move one cell and change state — simultaneously.
  • Reads happen before either write. If both agents write the same cell, the lower-numbered agent wins.
  • There is no HALT state. A run halts only when both agents occupy the same cell after a step.

Machine format

machine1|machine2 in bbchallenge standard format: rows separated by _, each entry is write + move + next state. For example 1RB means write 1, move Right, go to state B. --- is an undefined transition.

Diagram

Time runs downward. Each row is a slice of simulated time, columns are tape cells. Every symbol has its own grey level: black is symbol 0 and white is the highest symbol — the rest is an even black-to-white gradient, so it works for any number of symbols.

  • Head markers are green when the head moved left and red when it moved right. Agent 1 is drawn brighter than agent 2.
  • Click or drag on the diagram to move through time; a yellow ring marks the collision that halts the run.
  • Simulation Parameters sets how many steps are run, how many tape cells are visible, where the tape sits horizontally, and the initial tape content in 0s and 1s.
